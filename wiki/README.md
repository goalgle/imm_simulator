## 정리 원칙

- **코드 현실 채택**: 중복되는 아이디어는 현재 구현 기준으로 적었다. 옛 안 (의학적 7종, weakness 모델, tempState, DNA hex code 등) 은 [기획/비전.md §부록](기획/비전.md#부록---폐기된-옛-안) 에 짧게만.
- **명세는 코드와 1:1**: 함수·필드·상수 이름을 그대로 인용. 코드가 바뀌면 명세도 바꿔야 함.
- **A/B/C 라벨 없음**: 옛 docs/ 의 옵션 보존 방식 폐기. 분기는 부록에 한 줄로.
