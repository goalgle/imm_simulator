# 진행 시스템 — 특전 + 스킬

> 스테이지 클리어로 누적되는 영구 강화 두 가지: **특전(perk)** 과 **스킬 충전(skill)**.
> 둘 다 `src/domain/perks.ts` 의 module singleton — `scene.restart()` 를 넘어 유지, 첫 스테이지 진입 시 초기화.
> 작성·UI 흐름은 [docs/스크립트.md](../../docs/스크립트.md), 적용 시스템은 [시스템.md](시스템.md).

## 1. 왜 singleton 인가

스테이지 전환은 `scene.restart({ stageIndex })` 로 씬을 재구성한다. 인스턴스 멤버는 init/create 에서 리셋되므로, 스테이지 간 유지되어야 하는 누적 상태는 **module-level singleton** 으로 둔다 (`SoundSystem` 과 동일 패턴).

```typescript
// perks.ts
let SHARED: PerkState = freshPerkState();
let SKILLS: SkillCharges = { neutrophil: 1, bacteria: 1 };
```

`BloodScene.init` 에서 `currentStageIndex === 0` (게임 처음) 일 때만 `resetPerkState()` / `resetSkillCharges()`. 다음 스테이지로의 restart (`skipIntro=true`) 에선 유지.

## 2. 특전 (PerkState)

스테이지 클리어 → 결과 모달 → `다음 스테이지` → **특전 선택 화면** (7종 중 랜덤 3개 카드) → 1개 클릭 → `applyPerk` 누적.

### 2.1 7종 정의

| id | 이름 | 효과 | 누적 step | 적용 위치 |
|---|---|---|---|---|
| `speed` | 호중구 가속 | 이동속도 ×1.2 | 배수 곱 | WhiteCellBehavior speed |
| `superChance` | 슈퍼 호중구 촉진 | 슈퍼 생산 확률 +0.25 | 합 | MacrophageSystem |
| `tcell` | T세포 증원 | T세포 초반 +1 | 합 | populateStageStart |
| `bcell` | B세포 증원 | B세포 초반 +1 | 합 | populateStageStart |
| `nkChance` | NK 동원 | NK 생산 확률 +0.1 | 합 | MacrophageSystem |
| `hp` | 호중구 강화 | 체력 ×1.25 | 배수 곱 | WhiteCellBehavior spawn |
| `nutrientRegen` | 영양분 고갈 | 리젠 둔화 ×1.4 | 배수 곱 | 매 프레임 respawnDelayMul |

### 2.2 PerkState 필드

```typescript
type PerkState = {
  speedMul: number;          // 1 (배수)
  superBonus: number;        // 0 (가산 확률)
  tcellCount: number;        // 0
  bcellCount: number;        // 0
  nkBonus: number;           // 0 (가산 확률)
  hpMul: number;             // 1 (배수)
  nutrientRegenMul: number;  // 1 (배수)
};
```

**중첩 가능** — 같은 특전 반복 선택 시 배수는 곱(×1.2 두 번 = ×1.44), 가산은 합.

### 2.3 적용 디테일

- **속도/체력**: 호중구류 (NEUTROPHIL/SUPER/NK) 만. BCELL/TCELL 제외.
  - 속도: `WhiteCellBehaviorSystem` 의 매 프레임 speed 계산에 `× speedMul`.
  - 체력: `spawn` 시 dna 클론 후 `maxHp × hpMul` (호중구류만).
- **슈퍼 확률**: `MacrophageSystem.consumeScoreForProduction` — 기존 자격(호중구 점수 ≥ 40) 외에 `Math.random() < superBonus` 면 슈퍼 자격.
- **NK 확률**: NK 생산 확률 `(0.1 + nkBonus)`.
- **T세포/B세포**: `populateStageStart` 끝에 count 만큼 자동 spawn (place 와 별개, 모든 스테이지).
- **영양분 리젠**: 매 프레임 `respawnDelayMul = nutrientRegenMul × (세균 동적 rule)`. 둘 다 곱.

### 2.4 UI 흐름

`BloodScene.showPerkSelect(nextStageIndex)`:
1. 어두운 오버레이 + "특전 선택" 타이틀
2. 카드 3장 (`pickRandomPerks(3)`) — bg + 이름/설명 + 클릭 Zone
3. 카드 클릭 → `applyPerk(id)` + `addStageSkillCharges()` + `scene.restart({ stageIndex, skipIntro: true })`

## 3. 스킬 충전 (SkillCharges)

게임오버 방지용 **호중구 호출**, 점수용 **세균 호출**. 하단 스킬 바 버튼 또는 `[N]`/`[B]` 키.

### 3.1 모델

```typescript
type SkillCharges = { neutrophil: number; bacteria: number };
```

- **각각 별도** 충전. 기본 1.
- 스테이지 클리어 시 (특전 카드 선택과 함께 `addStageSkillCharges`) 각 +1.
- 사용 시 -1 (`useNeutrophilCharge` / `useBacteriaCharge` — 0 이면 false).
- **사용분 이월** — 안 쓴 충전은 다음 스테이지로 누적.

```
stage 0: reset → 호중구 1, 세균 1
  호중구 1회 사용 → 0, 1
클리어 → addStage → 1, 2
stage 1: singleton 유지 → 호중구 1, 세균 2
```

### 3.2 사용 효과

- 버튼/키 1회 → 해당 종 10마리 화면 무작위 spawn.
- 세균 스킬은 **infected 없는 일반 세균** (점수 누적용). `[B]` 디버그 키만 infected 2 (페이즈 2 트리거 검증).

### 3.3 버튼 UI

- 하단 스킬 바 (`SKILL_BAR_HEIGHT 64px`) — 좌 `+호중구 (N)`, 우 `+세균 (N)`.
- bg(Graphics) + 라벨(Text) + 클릭 Zone. `running` phase 에만 표시 (`setSkillBarVisible`).
- 충전 0 = 회색 + 클릭 무시.
