# 페이즈 2 — 풍선 안 wave + 변이 적용

> 호중구 1마리가 감염되면 그 호중구 위에 풍선이 떠서 wave 가 진행되고, 결과가 페이즈 1 로 반영되는 메커닉.
> 컨셉·이야기는 [기획/변이.md](../기획/변이.md). 코드 위치는 `src/scenes/BloodScene.ts` (단일 씬).

## 1. 풍선 (PhaseBubble)

페이즈 1 시뮬은 정지하지 않는다. 풍선은 별도 레이어로 떠 있다.

```typescript
type PhaseBubble = {
  host: WhiteCell;                  // 감염된 호중구 인스턴스
  localTime: number;                // 풍선 안 시간 (초). spawn 시 0
  spawnedAt: number;                // gameTime 기준 등장 시각
  resolvedAt: number | null;        // wave 종료 후 close 까지 카운트다운
  centerX, centerY: number;         // 화면 풍선 중심
  size: number;                     // 풍선 한 변 (정사각형, 둥근 모서리)
  wave: WaveState;
  viruses: Virus[];
  shieldHitEffects: ShieldHitEffect[];
  frameGfx, contentsGfx, virusLayer, hudText, resultText;
  closed: boolean;
  closing: boolean;                 // 페이드 아웃 진행 중
};
```

### 1.1 위치·외형

- 화면 우상단 + 30px 마진, 세로 정렬 (BUBBLE_SPACING 20).
- 한 변 240px (`BUBBLE_SIZE`). 둥근 사각형 (`BUBBLE_CORNER_RADIUS 24`).
- 외형: `BUBBLE_BG_COLOR 0x0a0a14` alpha 0.85 + `BUBBLE_BORDER_COLOR 0x88ccff` width 2.
- 꼬리(line): 풍선 가장자리 → host 까지 직선, `0x88ccff` width 1.5 alpha 0.6.
- 페이드 인/아웃: 0.3s.
- `depth = 1000` — 다른 모든 게임 객체 위.

### 1.2 동시 풍선 수

`BUBBLE_MAX = 3`. 풀 가득 차면 새 페이즈 2 진입 트리거 무시.

### 1.3 진입 트리거

세 경로:
1. **디버그**: `[Z]` 키 (수동 진입)
2. **Corruption finale**: corruption 변이 호중구가 scale 0 으로 소멸할 때 → 다른 호중구 1마리에 자동 진입
3. **Infected trigger** (페이즈 2 일반 진입): 미구현. Stage 8 작업 예정 — 바이러스 침공 이벤트 디자인 후

호스트 선정: NEUTROPHIL 후보 (NK/BCELL/TCELL/SUPER 제외) 중 무작위 1마리.

### 1.4 풍선 닫기 — closeBubble

다음 중 하나면 닫힘:
- wave 10발 모두 처리 → finalizeWave → 1.5s 결과 텍스트 표시 → close
- host 사망 (변이 적용 X)
- 디버그/restart

페이드 아웃 0.3s 후 모든 Graphics destroy.

## 2. 풍선 안 시간 — localTime

```typescript
bubble.localTime += dt;  // 외부 dt 공유 (speedMultiplier 도)
```

외부 `gameTime` 과 dt 를 공유. 빨리감기 시 풍선 안도 같이 빨라진다.

⚠️ **외부 시뮬은 절대 안 멈춤**. 옛 페이즈 2 안 (`scene.switch` + 정지) 폐기. 단일 BloodScene 에서 동시 진행.

## 3. DNA 시각화 — 10 세그먼트

풍선 중앙에 DNA 이중나선 그래픽. localTime 으로 회전 (1.5 rad/s).

- 시각상 10 구간으로 분할 — `DNA_SEGMENTS = 10`.
- 매 hit 마다 인덱스 0 부터 순차로 빨강 톤으로 부식.
- ⚠️ 세그먼트는 **시각용 추상**. 실제 DNA 형질의 1:1 매핑 아님. hit 카운트만이 변이 결정에 영향.

## 4. Wave 모델

| 항목 | 값 |
|---|---|
| Wave 당 바이러스 | **10발** 순차 spawn |
| Spawn 간격 | 0.8s |
| 패턴 분포 | 직진 4 / 지그재그 3 / 커브 3 (매 wave shuffle) |
| 바이러스 속도 | 40~80 px/s 랜덤 (도달 타이밍 분산) |
| 쉴드 charges | **5회** |
| 쉴드 지속 | 0.3s |
| Wave 종결 | 10발 모두 처리 (쉴드 차단 or DNA 도달) |

## 5. 바이러스 패턴

```typescript
type Virus = {
  kind: 'straight' | 'zigzag' | 'curve';
  bornTime: number;       // localTime 기준
  spawnX, spawnY: number;
  baseDirX, baseDirY: number;
  speed, amplitude, frequency: number;
  initialDist, initialAngle, angularVelocity, inwardSpeed: number;
  x, y: number;           // 현재 위치 (hit test)
  gfx: Phaser.GameObjects.Graphics;
};
```

| kind | 이동 |
|---|---|
| `straight` | spawn → 중앙 직선 |
| `zigzag` | 직선 경로 위에 수직 sin 진동 (`amplitude`, `frequency`) |
| `curve` | 중앙 기준 spiral (`angularVelocity` + 안쪽으로 `inwardSpeed`) |

**parametric position** 으로 계산. 매 프레임 dt 적분 X → 누적 오류 회피.

## 6. 쉴드

- 클릭 = `tryActivateShield`. charges 있고 비활성일 때만 발동.
- 활성 0.3s 동안 DNA strand/pair 라인 두께 ↑ 펄스.
- 한 번 발동으로 같은 타이밍의 다발 바이러스 다 차단 가능.
- 차단된 바이러스: `hits` 미증가 + 즉시 소멸 + 시안 원 펄스 (0.25s).

```typescript
type ShieldHitEffect = {
  x, y: number;
  bornTime: number;      // localTime
  gfx: Phaser.GameObjects.Graphics;
};
```

## 7. Hit 판정 — 관전/개입 모드

바이러스가 DNA 중심에 도달 (`VIRUS_HIT_RADIUS = 16`) 했을 때:

```typescript
const hitProb = this.interactive ? HIT_PROB_INTERACTIVE(1.0) : HIT_PROB_OBSERVE(0.4);
if (Math.random() < hitProb) {
  hits += 1;
  세그먼트[hits-1] 부식
}
바이러스 소멸
```

| 모드 | 풍선 클릭 | 바이러스 hit 확률 |
|---|---|---|
| 관전 (기본) | 무시 | 0.4 |
| 개입 | 쉴드 발동 | 1.0 |

## 8. Hit → 변이 매핑

```typescript
function pickMutation(hits: number): MutationKind | null {
  if (hits <= 0) return null;
  if (hits <= 2) return 'zombie';
  if (hits <= 4) return 'cancer';
  if (hits <= 6) return 'corruption';
  if (hits <= 8) return 'hyperactive';
  if (hits <= 9) return 'paralysis';
  return 'chaos';                  // hits >= 10
}
```

결정형 매핑. 랜덤 X. `src/domain/mutations.ts` — 26 단위 테스트 케이스.

## 9. 변이 적용 — finalizeWave

```typescript
function finalizeWave(bubble) {
  const kind = pickMutation(bubble.wave.hits);
  if (kind === null) {
    // 정상 — 변이 X. "변이 없음" 텍스트만
  } else {
    const newDna = applyMutation(bubble.host.dna, kind);
    bubble.host.setDna(newDna);             // dna 교체 + handle 갱신
    bubble.host.setMutation(kind);          // 라벨
    if (kind === 'cancer')       host.beginCancerDivide(gameTime);
    if (kind === 'corruption')   host.beginCorruption(gameTime);
    if (kind === 'hyperactive')  host.beginHyperactive(gameTime);
    if (kind === 'paralysis')    host.beginParalysis(gameTime);
    // "변이 N 발생" 텍스트 1.5s
  }
  bubble.resolvedAt = gameTime;
  // 1.5s 후 closeBubble
}
```

### 10.1 변이 1: zombie (hit 1~2)


### 10.2 변이 2: cancer (hit 3~4)

**dna 변경** (`mutationCancer`):

모양·떨림 유지 — "겉은 그대로, 속이 망가짐".

**시스템 분기** (entity 자체):
- `WhiteCell.updateAlive`: mutation==='cancer' → 행동 정지 + GRAVITY 80 으로 즉시 낙하.
- `cancerSpawnTime` 도달 시 (6s 후) 분열 요청 → `WhiteCellBehaviorSystem` 이 좌우로 새 cancer cell spawn (양쪽 임펄스 80 px/s).

## 11. 도메인 vs 시스템 분리 원칙

```
[domain/mutations.ts]  ← dna 의 시각·기본 행동 형질만 변경
        ↓
[entities/WhiteCell]   ← mutation 라벨 + mode timer (cancerSpawnTime 등)
        ↓ updateAlive 분기
[systems/*]            ← 매 프레임 행동 (정지/낙하/scale/폭발/마비)
                        + ContactSystem 의 데미지 분기
                        + BehaviorSystem 의 prey 후보 변경
[scenes/BloodScene]    ← 영역 데미지 (hyperactive) + 자동 페이즈 2 진입 (corruption)
                        + 외부 전파 (paralysis)
```

**왜 dna 만으로 안 되는가**: "정지/낙하/분열/scale/timer/폭발/마비 전파" 같은 메커니즘은 매 프레임 상태가 필요 — DNA (값 객체) 가 아닌 entity·시스템에 둠. dna 는 "정체성을 어떻게 보이게 할 것인가" 만 책임.

## 12. 풍선 클릭 hit test

```typescript
// 풍선 사각 영역 안인지
const dx = clickX - bubble.centerX;
const dy = clickY - bubble.centerY;
const half = bubble.size / 2;
if (|dx| <= half && |dy| <= half) {
  bubble 클릭으로 처리 (개입 모드면 쉴드, 관전 모드면 무시)
}
```

여러 풍선이 있을 때 위쪽(최근 spawn) 우선. 풍선 영역 밖 클릭은 페이즈 1 충격파.
