# 사운드 — Tone.js procedural audio

> `src/sound/SoundSystem.ts`. 파일 X — 모든 소리는 함수 합성 (게임 미학과 일관: 세포=함수=사운드도 함수).
> 트리거는 각 시스템에서 `getSoundSystem().play*()` 직접 호출.

## 1. 구조

- **Tone.js** (`^15`) — Web Audio 위 추상화. Phaser 와 별개 (Phaser=캔버스/입력, Tone=오디오 스레드).
- **module singleton** (`getSoundSystem()`) — `scene.restart()` 마다 새로 만들면 synth 누적/누수. 한 인스턴스 재사용.
- **모바일 정책**: AudioContext 는 첫 사용자 인터렉션 후에만 시작. `BloodScene` 이 첫 `pointerdown`/`keydown` 에 `ensureStarted()`. 그 전 모든 `play*()` 는 no-op (`started=false`).

## 3. 프리징 방지 — PolySynth + 시간 가드

**원인**: monophonic synth 에 **같은 `Tone.now()` 시각 동시 trigger** 시 Tone.js 가 `Error: Start time must be strictly greater than previous start time` throw. 매 프레임 throw → 다른 시스템 update 차단 → 프리징.

특히 영양분 흡수(`playBacteriaAbsorb`)는 매 프레임 여러 세균이 동시 발생 → 충돌 빈번.

**해결**:
- **두 노트/빈번 사운드 5종 → `PolySynth(Tone.Synth)`** — voice 자동 분리. 동시 trigger 충돌 X.
- **`MembraneSynth` / `PluckSynth`** (PolySynth wrap 불가 타입) → `nextTime` 추적 시간 가드:
  ```typescript
  const safeTime = Math.max(Tone.now(), this.contactNextTime + 0.02);
  synth.triggerAttackRelease(note, dur, safeTime);
  this.contactNextTime = safeTime;
  ```
  연속 trigger 가 항상 strictly greater. 빈도 낮으면 `Tone.now()` 가 따라잡아 지연 누적 없음.

## 4. 멜로디 (접촉) — 빈도 제어

`BloodScene.notifyContacts(dt)` 매 프레임:
- 호중구↔세균 페어 검사 (거리 < base 합).
- 페어당 `dt × TRIGGER_RATE(1.0)` 확률 trigger.
- **한 프레임 최대 1번** (`return` cap) — cacophony + voice 누적 방지.
- 격렬 전투(페어 多)여도 한 프레임 1번 → 자연 멜로디.

## 5. 사망 검출 — notifyDeaths

`BloodScene.notifyDeaths()` 매 프레임 (cleanupAbsorbed 전):
- `WeakSet<LivingCell>` 으로 새 사망 (hp=0) 1회만 트리거.
- 백혈구 → `playWhiteCellDeath`, 세균 → `playBacteriaDeath`.
- fusion 흡수 (hp>0 인데 isAbsorbed) 는 사망 아님 — 사운드 X.

## 6. 볼륨 밸런스

- 마스터 -10dB.
- 접촉 멜로디 -16dB (배경), 영양분 흡수 -18dB (빈번), 커맨더 -8dB / fusion -10dB / 분열 -14dB.
- 사망 사운드는 마스터 그대로 (도드라지게).

## 7. 코드 위치

- `src/sound/SoundSystem.ts` — 클래스 + `getSoundSystem()` singleton + `ensureStarted`
- 트리거: `BacteriaBehaviorSystem` (분열/흡수), `WhiteCellBehaviorSystem` (fusion), `TeamSystem` (공격명령), `BloodScene` (사망 검출 `notifyDeaths` + 멜로디 `notifyContacts`)
