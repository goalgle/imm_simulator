## 2. 백혈구 진영

### 2.1 NEUTROPHIL (호중구) 🪖

평범한 보병. 게임 시작부터 등장하고 가장 많이 본다.

- **성격**: 가장 가까운 세균을 둔하게 따라간다. 자체 추진 속도는 세균의 절반 (15 vs 30).
- **시각**: 연한 분홍 (`#E8B4D4`). 작은 base 16. 4·6·8 돌기로 부드럽게 떨림.
- **전투**: HP 100, 공격 20. 호중구가 약 5초 접촉하면 일반 세균 사망.
- **특수**: 자기 융합. HP < 25% 가 되면 약한 동료가 강한 동료를 찾아가 흡수됨. 2번 흡수한 호중구는 슈퍼로 진화.
- **약점**: 자체 속도 느림. 충격파로 보강해주는 게 플레이의 핵심.

### 2.2 NEUTROPHIL_SUPER (슈퍼 호중구)

호중구의 진화형. 시각이 확연히 다르다.

- **등장 경로** (2 가지):
  1. 대식세포가 호중구 시체를 충분히 흡수했을 때 (호중구 점수 ≥ 40)
  2. 호중구 자기 융합 (HP 낮은 동료를 흡수 → 2회 누적 → 본인이 슈퍼로)
  3. T세포 영역에서 호중구가 level 5 도달 시 1/3 확률
- **시각**: 진한 보라 (`hsl 280, 65%, 55%`). base 20.
- **전투**: HP 180, 공격 30. 일반보다 거의 두 배 강함.
- **속도**: 32 (일반의 두 배), turnRate 2.0.

### 2.3 NK_CELL (Natural Killer)

암살자. 게임의 균형추 역할.

- **등장 경로**: 대식세포 호중구 생산 시 1/10 확률 + T세포 영역에서 호중구 레벨 5 → 1/3 확률.
- **표적 우선순위**: 세균 커맨더 1순위 (`seekCommander 1.5`). 없으면 일반 세균.
- **회피**: 일반 세균은 80px 안에서 우회 (`avoidWorker 0.4`). 직접 싸우지 않는 톤.
- **시각**: 다크 인디고 (`hsl 240, 70%, 25%`). 작은 base 13. 5·7·9 돌기로 빠른 떨림.
- **전투**: HP 80 (약함), 공격 35 (가장 강함). 한 방 맞으면 위험하지만 커맨더는 빨리 처치.
- **특수**: HP 가 줄어도 속도 유지 (`minSpeedRatio 1.0`). 빈사여도 풀 스피드.

### 2.4 BCELL (B 세포)

미사일 기지. 거의 정지 + 원격 공격.

- **등장**: 게임 시작 시 placing 단계에서 1마리 배치 + T세포 진화로 추가.
- **시각**: 연보라 (`hsl 232, 50%, 70%`). base 10. 2·3·4 돌기로 거의 원형.
- **전투**: HP 50 (가장 약함), 공격 0 (직접 X).
- **무기**: 항체(antibody) 발사. 3초마다 1발, 사거리 250px, 데미지 15.
- **항체 특성**: 영양분처럼 보여 세균이 끌려옴 → 흡수 시 HP 감소. 사거리 만료 시 정지 = 지뢰화.
- **누적 방지**: 정지 항체 최대 5개. 초과 시 가장 오래된 것부터 자동 정리.

### 2.5 TCELL (T 세포)

지휘관. 직접 싸우지 않지만 호중구를 키운다.

- **등장**: 게임 시작 시 placing 단계에서 1마리 배치.
- **시각**: 진한 청록 (`hsl 186, 50%, 40%`). base 12.
- **행동**: 호중구 무리 따라다님 (`seekAlly 1.0`).
- **전투**: HP 100, 공격 0 (직접 X).
- **특수 — 호중구 진화**: 지휘범위(200px) 안 호중구가 세균을 처치하면 그 호중구 `level += 1` + HP 30% 회복. level 5 도달 시 자기 자리에서 NK / BCELL / SUPER 중 1/3 확률로 진화.
- **T세포는 진화 X**: 자기 자신은 그대로.

### 2.6 MACROPHAGE (대식세포)

청소부. 바닥에 고정.

- **등장**: 게임 시작 시 1마리. 화면 바닥 좌우만 이동.
- **시각**: 초록 (`hsl 120, 30%, 50%`). base 13. 시각상 `setScale(1, 0.55)` 로 납작.
- **인터렉션**: 시체(`isSettled()`) 만 처리. 살아있는 세포·세균·충격파 모두 무시.
- **점수**: 세균 시체 +10, 호중구 시체 +20. 100점 도달 시 새 호중구 1마리 자기 위치에서 위로 솟구침.
- **조작**: 자동으로 가장 가까운 시체 추적. `← →` 키 누르면 0.5s 동안 수동 조작.

## 3. 세균 진영

### 3.1 BACTERIA_A (일반 세균)

영양분 일꾼.

- **성격**: 영양분 추구 + 백혈구 회피. 시야(180px) 안 백혈구 있으면 도망.
- **시각**: 어두운 회색 (`hsl 0, 0%, 30%`). 작은 base 9. 5·7·9 돌기 — 호중구보다 불규칙.
- **분열**: 영양분 3개 흡수 → 0.5s 부풀음 → 자기 복제 1마리.
- **전투**: HP 60 (호중구 절반), 공격 15.
- **소속**: 커맨더 근처면 팀 멤버로 영입됨. 팀 모드(`aggressive`/`defensive`) 에 따라 행동 변동.

### 3.2 BACTERIA_COMMANDER (세균 커맨더)

지휘관. 무리를 모은다.

- **등장**: placing 단계에서 1마리 배치 + 죽으면 10초 뒤 일반 세균 1마리가 자동 진화.
- **시각**: 짙은 자주 (`hsl 330, 50%, 25%`). 일반(base 9)보다 큰 base 10. 회색 일반과 명확히 구분.
- **시야 분리**: 회피 시야 180 (가까이 와야 도망) + 공격 결정 시야 540 (멀리서 호중구 인지하여 팀 모드 결정).
- **전투**: HP 120, 공격 25 (일반보다 강).
- **분열 X**: 영양분 흡수 시 시야/지휘범위 ↑ + 레벨업. 5개 흡수 = 1 레벨, 3 레벨마다 최대 팀원 +1.
- **팀 모드**:
  - 멤버 < baseTeamSize(3) → 강제 `defensive`
  - 시야 안 표적 + 팀 HP > 표적 HP × 1.5 → `aggressive` + 멤버들이 표적 돌격
  - 그 외 → `defensive`
- **공격 톤**: 커맨더 자신은 후방. 직접 돌진 X. 멤버만 표적으로 향한다.

## 4. 표적 우선순위 — 세균 입장

세균 (특히 aggressive 팀) 이 노리는 백혈구 우선순위:

1. **BCELL** — 정지 + 약체 + 항체 위협 차단
2. **TCELL** — 호중구 진화 매개 차단
3. **NEUTROPHIL / NEUTROPHIL_SUPER / NK_CELL** — 직접 전투 대상

같은 우선순위 안에서는 가장 가까운 것. 다른 우선순위 사이에선 거리 무관으로 우선 순위가 압도.

## 5. 시뮬레이션 균형 — 종 간 관계

```
세균이 호중구를 많이 잡으면
   → 호중구 사체 누적
   → 대식세포 점수 ↑
   → 슈퍼 호중구 생산 (호중구 점수 ≥ 40)
   → 면역 반격
   → 세균 약화

세균 커맨더가 무리를 끌고 진격하면
   → BCELL 1순위 타겟됨
   → 항체 줄어듦
   → 세균 압박 ↑
   → NK 등장하면 커맨더 빠르게 제거
   → 팀 와해

호중구가 약해지면
   → 강한 동료 찾아감 (자기 융합)
   → 슈퍼 호중구 (내부 회복)

T세포 주변에서 호중구가 세균 처치
   → 그 호중구 레벨업 + HP 회복
   → 5레벨에서 NK/BCELL/SUPER 진화
   → 영역 안에서 사실상 무한 전투
```

이 사이클 어디에 손을 대도 균형이 깨진다. 새 종을 넣을 때는 어느 사이클에 균형추가 되는지 정의해야 한다.

## 6. 시각적 구분의 원칙

- **HSL 채택 이유**: hue 만 바꿔도 종족이 구분되도록. 변이가 색조만 바꿀 때 명도·채도 따로 유지.
- **base 크기로 위계**: 일반 호중구 16, 슈퍼 20, 세균 커맨더 10. 큰 게 강한 톤.
- **n (돌기 수)**: 호중구 4 (둥글), 세균 5 (불규칙), 슈퍼 4 (호중구와 동일 wave 형태).
- **omega (떨림 속도)**: NK 4.0 (가장 빠름, 암살자 톤). 호중구 2.5, 대식세포 0.5 (느림, 무거움).
