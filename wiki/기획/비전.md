# 비전 — 게임이 보여주려는 것

> 이 파일은 코드와 무관한 디자인 의도를 정리한다. "왜 이렇게 만드는가" 에 답한다.
> 구현된 결과는 [명세/](../명세/) 참조.

## 1. 한 줄 컨셉

**바이러스·세균이 침입한 몸 속을 관전하는 시뮬레이션.** 손은 가볍게만 댄다. 세포들은 자기 의지대로 살고 죽는다.

- 게임 타입: 관전형 + 결정적 개입 (수동 슈팅 X)
- 분위기: 의학 일러스트의 차분함 + 생체의 꿀렁임
- 핵심 즐거움: "내가 안 봐도 게임이 굴러간다" 는 것을 보다가, 결정적인 순간 한 번 개입하는 만족감

## 2. 두 가지 원칙

### 2.1 모든 세포는 함수다

세포는 비트맵 스프라이트가 아니다. 매 프레임 polygon 을 다시 그리는 `r(θ, t)` 함수의 평가 결과이다.

```
r(θ, t) = base + Σ A_i · sin(n_i · θ + ω_i · t + phase)
```

- 파라미터(`base`, `A`, `n`, `ω`)는 모두 DNA 의 한 필드
- 시간 `t` 만 흐르면 모양이 살아 움직인다
- 정지하면 — 죽었거나, 멈출 만한 시각 자극을 받았다는 뜻

이 원칙이 게임의 시각적 정체성을 만든다. 폴리곤 모음이 아닌 "함수 그래프가 살아있는" 인상.

### 2.2 DNA 는 정본, 나머지는 파생

세포의 모든 형질 — 모양·색·속도·드라이브 가중치·공격력·시야 — 은 **하나의 DNA 객체**에 들어있다.

- 변이는 "DNA 의 일부 필드를 산술 변형" 한 결과. 새 클래스를 만들지 않는다.
- UI 의 16진수 코드 (`#A34C-...`) 같은 표시는 정본의 단방향 파생일 뿐.
- 새 종족 추가 = 새 프리셋 한 덩어리. 코드는 거의 안 늘어난다.

이게 게임 디자인을 "데이터 작성"으로 떨어뜨린다. 코드 수정 없이 종을 늘릴 수 있어야 한다.

## 3. 인터렉션 톤

플레이어가 손대는 지점은 세 군데뿐이다.

| 어디 | 무엇 | 왜 |
|---|---|---|
| 페이즈 1 클릭 | 충격파 (반발) | "혈류 펌핑" 같은 손짓. 무제한 X — 5 charges, 3초당 1발 |
| 풍선 (페이즈 2) 클릭 | 쉴드 (바이러스 차단) | 개입 모드에서만 활성. 5 charges, 0.3s |
| `← →` 키 | 대식세포 좌우 조작 | 화면 바닥에서 시체 청소를 직접 안내 |

키보드는 단축키 (`[1]/[2]/[3]` 빨리감기, `[P]` 일시정지, `[I]` 관전/개입 모드 토글 등) 중심.

**중요**: 페이즈 1 충격파는 데미지 X. 미는 힘만. 세균을 죽이는 건 백혈구의 일.

## 4. 시각의 3 채널

생체의 자극은 3채널로 분리해 표현한다. 채널이 곧 의미.

| 채널 | 트리거 | 시각 |
|---|---|---|
| **shock** | 충격파 임펄스 | 자기 색이 진해짐 (채도 ↑, 명도 ↓) |
| **combat** | 세균·호중구 접촉 | 색이 빨강 쪽으로 lerp |
| **life** | hp=0 | 채도 0 + 떨림 정지 (회색) |

세 채널이 동시 작용 가능. "충격파 맞으면서 세균과 싸우는 호중구는 약간 빨개진 진한 분홍이 떨린다." 새 자극이 생기면 채널을 늘리지, ad-hoc 분기를 안 쓴다.

## 5. 자가 균형

게임이 스스로 굴러가야 한다. 외부 개입 없이도 한쪽이 일방적으로 이기지 않는 사이클이 디자인된다.

```
세균 강함 → 호중구 사체 많음
         → 대식세포 점수 ↑
         → 슈퍼 호중구 생산
         → 면역 반격
         → 세균 약화
         → 호중구 사체 적음 → 평범 호중구만 → 사이클 회복
```

**추가 회복 경로**:
- 호중구 자기 융합 (약한 동료 흡수 → 슈퍼)
- T세포 영역 안에서 호중구 처치 → 레벨업 → 5레벨 → NK/BCELL/SUPER 진화
- 커맨더 죽으면 10초 뒤 일반 세균 1마리가 자동 진화

이 디자인이 깨지지 않게 새 메커닉은 항상 양쪽에 균형추를 둔다.

## 6. 페이즈 분리 — 매크로 / 미시

| 페이즈 | 보는 것 | 인터렉션 강도 |
|---|---|---|
| **1** (혈관 속) | 백혈구 vs 세균 군집 | 낮음 (관전 + 충격파) |
| **2** (호중구 내부) | DNA + 바이러스 wave | 중간 (쉴드, 개입 모드 시) |

페이즈 2 는 풍선(bubble) 으로 페이즈 1 위에 떠 있다. 페이즈 1 시뮬은 안 멈춘다. 한 호중구가 감염되면 그 호중구 위에 풍선이 떠서 그 안에서 wave 가 진행되고, 결과(변이)가 다시 페이즈 1 로 반영된다.

## 7. 부록 — 폐기된 옛 안

다음은 최초 기획서에 있었으나 코드 구현 단계에서 다른 길로 간 안이다. 정리만 해둔다.

- **의학적 백혈구 7종** (호중구·호산구·호염기구·B/T/NK·대식세포): 호산구·호염기구는 게임 디자인에 안 들어왔다. 코드는 호중구·NK·B·T·슈퍼호중구·대식세포 + 세균 2종 = 8 프리셋.
- **weakness 0~1 누적 + 자동 회복** 약화 모델: HP 정수 + `applyDamage`/`heal` 모델로 단순화.
- **tempState (interference/damping/phaseShock)** 접촉 반응: VisualState 3채널 (shock/combat/life) 로 정리.
- **DNA 의 `#A34C-5F2E-...` 16진수 UI 코드**: 정본 객체로 충분. 단방향 파생 함수만 후보로 남김.
- **장면 2 의 A/D 키 수동 슈팅**: "관전형" 톤과 충돌. 쉴드 + 자동 wave 진행으로 교체.
- **DNA 세그먼트 ↔ 형질 1:1 매핑**: 10 세그먼트는 시각용 추상. 실제 변이는 hit 카운트로만 결정.
