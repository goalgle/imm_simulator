# 게임플레이 — 무엇을 보고 무엇을 누르는가

> 플레이어가 실제로 겪는 흐름. 룰·조작·HUD·승패. 메커닉의 *시각·체험* 측 정리.
> 메커닉의 *수치·구현* 은 [명세/시스템.md](../명세/시스템.md) / [명세/페이즈2.md](../명세/페이즈2.md).

## 1. 흐름 한 장

```
[게임 시작]
  ↓
인트로 컷신 (Session 21)
  - 대본형 narration + ACTION 으로 영양분/세균/호중구 소개
  - 클릭으로 다음 라인. 일부 ACTION 중엔 sim 진행.
  ↓
placing 단계
  - T세포 / 세균 커맨더 / B세포 클릭 배치
  - 미리보기 셰입 따라다님. 배치 끝나면 자동 running.
  ↓
running (스테이지 1 — 180초)
  - 호중구 vs 세균. 충격파 / 대식세포 조작 / 모드 토글.
  - 60s, 120s 에 세균 추가 wave 자동 spawn.
  - 호중구 풍선(페이즈 2) 가 자동 발생, 그 안에서 wave 진행, 변이 결과 페이즈 1 로.
  ↓
종료 판정
  - 세균 전멸 → 시간 클리어 ★★★
  - 시간 초과 → 잡은 비율로 ★★ (80%↑) / ★ (50%↑) / 실패
  - 호중구 (NEUTROPHIL/NK/SUPER) 전멸 → 즉시 실패
  ↓
결과 모달
```

## 3. 단계 머신 (BloodScene.phase)

| 단계 | 동작 | 외부 sim |
|---|---|---|
| `cutscene` | 인트로 텍스트 박스 + ACTION (영양분/세균/호중구 spawn). 클릭으로 다음 라인. | ACTION 따라 켜짐 |
| `placing` | 마우스 따라 미리보기 셰입. 클릭 = 배치 + 다음. 큐 비면 자동 `running`. | 정지 |
| `running` | 정상 시뮬레이션. 페이즈 2 풍선은 위에 떠 있는 별도 레이어. | 진행 |

추가로 스테이지 상태:

| stageState | 의미 |
|---|---|
| `running` | 시간 카운트, wave 스케줄, 판정 검사 |
| `resolved` | 결과 모달 표시 중. sim 정지 |

## 4. 조작

### 4.1 마우스

| 행동 | 단계 | 효과 |
|---|---|---|
| 클릭 (cutscene) | cutscene | 다음 narration 라인 / 다음 step |
| 클릭 (placing) | placing | 미리보기 위치에 배치 |
| 클릭 (running, 빈 공간) | running | 충격파 발사. 임펄스를 가까운 세포에 |
| 클릭 (running, 풍선 내부) | running, 개입 모드 | 쉴드 발동 (charges 있고 비활성일 때) |

### 4.2 키보드

| 키 | 효과 |
|---|---|
| `[1]` `[2]` `[3]` | 빨리감기 1× / 2× / 4× |
| `[P]` | 일시정지 / 재개 |

| `[I]` | 관전 ↔ 개입 모드 토글 |

| `[Z]` | 디버그: 페이즈 2 강제 진입 |
| `[N]` `[B]` | 디버그: 호중구 +10 / 세균 +10 |

## 5. 관전 vs 개입 모드

`[I]` 로 토글. 페이즈 2 의 hit 확률이 달라진다.

| 모드 | 풍선 클릭 | 바이러스 hit 확률 | 의미 |
|---|---|---|---|
| 관전 (기본) | 무시 | 0.4 | "면역계가 알아서 한다" — 60% 자동 차단 |
| 개입 | 쉴드 | 1.0 | "내가 막아야 한다" — 쉴드 안 쓰면 다 통과 |

같은 게임을 두 가지 톤으로 즐길 수 있게 한 디자인. 진행 중 wave 에도 즉시 반영된다.

## 6. 충격파 (페이즈 1 인터렉션)

- 5 charges 보유, 3초당 1발 자동 충전.
- 클릭 지점에서 파동이 280 px/s 로 1.2s 동안 퍼짐.
- 영향권 (band 50px) 안 세포에 발사점 *반대* 방향 임펄스 누적.
- **데미지 X**. 미는 힘만.
- 영양분·시체·대식세포는 영향 없음.

용도:
- 위급한 호중구를 세균에서 떼어내기
- 한쪽으로 몰린 세균을 분산
- 호중구를 영양분 쪽으로 유도 (호중구는 영양분과 통과만 — 자체 의지로는 안 감)

| 항목 | 값 |
|---|---|

| 시작 호중구 | 10 |

| ★ | 시간 초과 + 잡은 비율 50%↑ |

시간은 `gameTime` 기준 — 빨리감기를 켜면 실제 경과 시간이 짧아진다.

## 8. 컷신 (Session 21 → 2026-05-21 리팩토링)

대본 형태 (`src/cutscenes/intro-script.ts`). 여섯 종류 step:

- **narration**: 단어별 타이핑 (0.12s/단어) → 라인 사이 0.4s pause → 라인 끝나면 클릭 대기
- **control(kind, partial)**: EntityRegistry 즉시 갱신 후 다음 step. 예: `control('bacteria', { frozen: true })`
- **spawn(kind, count, area?)**: 지정 종 spawn. `interval > 0` 면 순차, 0 면 일괄
- **pause(seconds)**: 시간 대기 후 다음 step
- **waitFor(condition, maxSeconds)**: 게임 상태 조건 충족까지 대기 (maxSeconds 안전망)
- **end**: 컷신 종료 → placing 또는 running

조건 종류: `'nutrientsConsumed'`, `'bacteriaEliminated'`, `'neutrophilsEliminated'`, `'whiteCellsEliminated'`.

기존 `action('spawnNutrients')` 같은 ACTION 핸들러는 제거되고 선언적 step 조합으로 마이그레이션. 대본 자체가 "무엇이 등장하고, 무엇이 정지되고, 어떤 게임 사건을 기다리는가" 를 다 보여줌.

예:
```typescript
control('nutrient', { enabled: true }),
spawn('nutrient', 5, { spread: 120, interval: 0.5 }),
pause(0.6),                                  // 짧은 호흡
control('bacteria', { enabled: true, frozen: false }),
spawn('bacteria', 2, { spread: 80 }),
waitFor('nutrientsConsumed', 15),            // 세균이 영양분 다 먹을 때까지
```

인트로는 5분 정도 — 영양분 → 세균 → 호중구 → 커맨더 사전 도입까지. 화면 우상단에서 wave 가 자연스럽게 도착하는 톤.

## 9. 페이즈 2 진입 — 풍선

호중구 1마리가 감염되면 그 호중구를 호스트로 풍선이 떠오른다.

- 풍선 = 둥근 사각형 + 호스트와 line 연결
- 외부 sim 정지 X — 페이즈 1 시뮬레이션이 그대로 계속 진행
- 동시 최대 3개 풍선
- 풍선 안에서 10발 바이러스 wave 자동 진행 (0.8s 간격 spawn, 4 직진 + 3 지그재그 + 3 커브)
- 바이러스가 DNA 중심에 닿으면 hit 카운트 +1, 화면상 DNA 세그먼트 하나가 빨갛게 부식
- 쉴드 (개입 모드) = 0.3s 동안 활성, DNA strand 두께 ↑ 펄스
- wave 10발 끝나면 hit 카운트로 변이 종류 결정, 호스트에 적용, 풍선 닫힘
