# 컷신 / 스테이지 스크립트 매뉴얼

> 이 문서는 면역 시뮬레이터의 **이벤트 컷신** 과 **스테이지** 를 텍스트로 작성하는 방법을 다룹니다.
> 코드 변경 없이 스크립트만 편집해서 새 인트로 / 스테이지를 추가할 수 있도록 설계됨.

## 디렉토리 구조

```
src/cutscenes/
  types.ts           — CutsceneStep 타입 + helper 함수 (narration, spawn, control, ...)
  intro-script.ts    — 게임 첫 진입 시 1회 재생되는 글로벌 인트로 (튜토리얼)

src/stages/
  types.ts           — StageConfig 타입 정의
  all.ts             — STAGE_1 ~ STAGE_10 정의 + STAGES 배열
```

## 기본 개념 — 두 종류의 스크립트

| 구분 | 글로벌 인트로 (CUTSCENE_INTRO) | 스테이지 (STAGE_N) |
|---|---|---|
| 위치 | `cutscenes/intro-script.ts` | `stages/all.ts` |
| 재생 시점 | 게임 첫 진입 1회 | 매 스테이지 진입 |
| 형식 | 단일 step 배열 | `intro` / `setup` / `waves` 등 구조화된 객체 |
| 스킵 키 | `[S]` 또는 `[ESC]` | `[S]` 또는 `[ESC]` (intro 단계에서) |

## 1. CutsceneStep — 모든 step 의 사용법

모든 step 은 `import { 함수명 } from './types'` 로 import 후 호출하여 객체 반환.
`intro-script.ts` 와 `stages/all.ts` 둘 다 동일한 step 들을 사용함.

### 1.1 `narration(text)` — 일반 텍스트 안내

단어별 타이핑 + 클릭으로 진행. 여러 줄은 자동 진행 (라인 사이 짧은 pause).

```ts
narration(`
  캄캄하죠?
  당신의 혈관입니다.
  세균이 침입했어요.
`)
```

- 들여쓰기 / 빈 줄은 자동으로 무시.
- 모든 라인 표시 완료 시 우측 하단에 "▼ 클릭" 힌트 표시.
- 사용자 클릭으로 다음 step 진행.

### 1.2 `warning(text)` — 강조 안내 (붉은 굵은 글씨 + 흔들림)

`narration` 과 동작 동일. 시각만 다름 — 색 `#ff5566`, bold, 매 프레임 ±1.5px jitter.

```ts
warning(`
  주의! 게임적 허용입니다.
  실제 생물학과는 다릅니다.
`)
```

### 1.3 `control(kind, partial)` — 종족별 제어

`EntityRegistry` 에 즉시 적용 후 다음 step. timer 없음.

```ts
control('bacteria',  { enabled: false, frozen: true }),
control('neutrophil', { enabled: true, speedMul: 2 }),
control('nutrient',  { enabled: false }),
```

**dimension (`EntityControl` 필드)**:
- `enabled` — 새 spawn 허용 여부
- `visible` — 화면 표시 여부
- `frozen` — 행동 정지 (충돌·시각도 정지)
- `speedMul` — 속도 배수 (1=정상, 0=정지)
- `spawnProb` — 등장 확률 (NK 1/10 같은 분기에)

**kind (`EntityKind`)**: `nutrient` · `bacteria` · `bacteriaCommander` · `neutrophil` · `neutrophilSuper` · `nk` · `bcell` · `tcell` · `macrophage` · `antibody` · `bubble`

### 1.4 `spawn(kind, count, area?)` — 개체 등장

```ts
spawn('bacteria', 5, { spread: 200, interval: 0.5, sparkleSeconds: 1.0 }),
spawn('neutrophil', 10, { spread: 300 }),
spawn('macrophage', 1),
spawn('bacteria', 3, { spread: 250, infectedChance: 0.5 }),
```

**area 옵션**:
- `cx, cy` — 중심 좌표. 생략 시 화면 중앙.
- `spread` — ±spread 사각 박스 안 무작위. 0 = 정확한 위치.
- `interval` — 순차 spawn 간격 (초). 0 = 일괄.
- `sparkleSeconds` — spawn 위치에 노란 원 펄스. spawn 완료 후 그 시간만큼 step 머묾.
- `infectedChance` — 0~1, spawn 한 개체가 바이러스 보유 확률. `bacteria` / `bacteriaCommander` 에만 의미.

### 1.5 `place(kind, label)` — 사용자가 클릭으로 배치

step 자체는 즉시 advance — `placementQueue` 에 등록만. 컷신 / 스테이지 setup 종료 시 큐 순서대로 placing 단계가 시작.

```ts
place('tcell', 'T세포 (대장세포)'),
place('bacteriaCommander', '세균 커맨더'),
place('bcell', 'B세포'),
```

지원 종: `neutrophil` · `neutrophilSuper` · `nk` · `bcell` · `tcell` · `bacteria` · `bacteriaCommander`.
미지원 (warn): `macrophage` · `nutrient` · `antibody` · `bubble`.

### 1.6 `pause(seconds)` — 시간 대기

```ts
pause(2),   // 2초 대기 후 다음 step. 시뮬레이션은 그동안 계속 진행 (frozen 안 됐다면)
```

### 1.7 `waitFor(condition, maxSeconds)` — 게임 상태 대기

조건 충족 또는 maxSeconds 도달 시 (둘 중 먼저) 다음 step.

```ts
waitFor('nutrientsConsumed', 15),
waitFor('bacteriaEliminated', 20),
waitFor('neutrophilsEliminated', 30),
waitFor('whiteCellsEliminated', 60),
```

**condition 종류**:
- `nutrientsConsumed` — 모든 영양분 흡수됨
- `bacteriaEliminated` — 살아있는 세균 0
- `neutrophilsEliminated` — 살아있는 호중구류 (NEUTROPHIL/NK/SUPER) 0
- `whiteCellsEliminated` — 살아있는 모든 백혈구 0

### 1.8 `waitForShockwaves(count, maxSeconds)` — 충격파 N번 대기

사용자가 화면을 N번 탭/클릭해서 충격파 발사할 때까지. step 진입 시 카운터 0 reset.
컷신 중에도 이 step 동안엔 화면 탭이 충격파 발사로 동작 (다른 step 에선 narration 진행 등 평소 동작).

```ts
waitForShockwaves(6, 60),  // 6번 발사 또는 60초 후 진행
```

### 1.8b `waitForBacteriaKilled(count, maxSeconds)` — 세균 N마리 처치 대기

step 진입 후 추가로 사망한 세균 수가 count 도달 또는 maxSeconds 시 진행.
진입 시점의 누적 처치 수를 baseline 으로 잡아 그 이후만 카운트. 분열/wave 무관 — 사망만.

```ts
waitForBacteriaKilled(2, 15),  // 호중구가 2마리 잡으면 (또는 15초) 진행
```

### 1.8c `waitForMacrophageProductions(count, maxSeconds)` — 대식세포 호중구 생산 N회 대기

step 진입 후 대식세포가 호중구를 count 마리 생산하면 진행 (시체 흡수 → 100점 → 1마리).

```ts
waitForMacrophageProductions(3, 60),  // 대식세포가 3마리 생산하면 (또는 60초) 진행
```

### 1.9 `evolveCommander(afterSeconds)` — 커맨더 진화 트리거

`afterSeconds` 초 후 일반 세균 1마리가 자동으로 커맨더로 진화. 즉시 advance — 백그라운드에서 진행.

```ts
evolveCommander(2),   // 2초 후 자연 진화
```

### 1.10 `nutrientRegen(options)` — 영양분 부활 설정

부활 영역 set + 즉시 N개 활성화. 즉시 advance.

```ts
nutrientRegen({
  half: 120,                                        // ±half 사각 박스
  initialCount: 8,                                  // 즉시 활성화 슬롯 수
  slowWhenBacteriaAbove: { count: 20, regenMul: 0.5 },  // 동적 조절
}),
```

`cx`/`cy` 생략 시 살아있는 백혈구 centroid 자동 (없으면 화면 중앙).

### 1.11 `clear()` — 화면의 모든 entity 정리

백혈구·세균 (살아있음/시체) · 대식세포 · 영양분 · 항체 · 풍선 모두 정리. registry 는 유지.

```ts
clear(),
pause(2),
```

### 1.12 `end()` — 컷신 종료

`intro-script.ts` 의 마지막에 명시. 스테이지 `intro` 에서는 생략해도 자동 종료.

```ts
end(),
```

## 2. 글로벌 인트로 작성 — `intro-script.ts`

게임 첫 진입 시 1회 재생. `[S]` 또는 `[ESC]` 로 스킵 가능.

```ts
// src/cutscenes/intro-script.ts
import { narration, control, spawn, pause, waitFor, place, end, ... } from './types';

export const CUTSCENE_INTRO: CutsceneStep[] = [
  // 초기 상태 — 모든 종 비활성. 각 step 이 필요한 것만 enabled.
  control('nutrient',   { enabled: false }),
  control('bacteria',   { enabled: false, frozen: true }),
  control('neutrophil', { enabled: false }),

  narration(`
    캄캄하죠? 당신의 혈관입니다.
  `),

  // 영양분 소개
  control('nutrient', { enabled: true }),
  spawn('nutrient', 5, { spread: 60, interval: 0.5, sparkleSeconds: 1.0 }),
  pause(0.6),

  narration(`혈장 영양분입니다.`),

  // ... 다른 종 소개 ...

  // 마지막 사용자 배치 (T세포 / 세균 커맨더 / B세포)
  place('tcell', 'T세포 (대장세포)'),
  place('bacteriaCommander', '세균 커맨더'),
  place('bcell', 'B세포'),

  end(),
];
```

**작성 가이드**:
- `control('xxx', { enabled: false })` 로 시작 → 필요할 때만 `enabled: true` 로 켜기.
- `narration` 과 시뮬레이션 step 을 번갈아 — "설명 → 시연 → 설명" 흐름.
- 마지막에 `place()` 들 + `end()`.

## 3. 스테이지 작성 — `stages/all.ts`

```ts
// src/stages/all.ts
import { narration, spawn, pause, nutrientRegen, place } from '../cutscenes/types';
import type { StageConfig } from './types';

export const STAGE_3: StageConfig = {
  id: 'stage-3',
  title: '두 지휘관',

  // 진입 시 짧은 컷신 (narration / pause 등). 생략 가능.
  intro: [
    narration(`
      적 지휘관이 둘이에요.
      각자의 무리를 이끌어 협공해옵니다.
    `),
  ],

  // 본게임 시작 시점 일괄 적용 (timer 없음).
  setup: [
    spawn('neutrophil', 9, { spread: 300 }),
    spawn('bacteria', 4, { spread: 200 }),
    spawn('bacteriaCommander', 2, { spread: 200 }),
    spawn('macrophage', 1),
    nutrientRegen({ half: 160, initialCount: 10 }),
  ],

  // 시간 흐름 이벤트 — atSec 오름차순 권장.
  waves: [
    { atSec: 60,  steps: [spawn('bacteria', 4, { spread: 250 })] },
    { atSec: 120, steps: [spawn('bacteria', 4, { spread: 250 })] },
  ],

  // 시간 제한 (초). 초과 시 timeout.
  timeLimit: 180,

  // 종료 조건 — 매 프레임 검사, 첫 일치가 결과.
  endConditions: [
    { check: 'bacteriaEliminated',   result: 'clear' },
    { check: 'neutrophilsEliminated', result: 'wipe' },
  ],

  // 별점 임계 (timeout 시 killed/total 비율로 결정).
  stars: { twoRatio: 0.8, oneRatio: 0.5 },
};
```

### 3.1 필드 설명

| 필드 | 설명 |
|---|---|
| `id` | 고유 식별자 (`stage-3` 같은 kebab-case 권장) |
| `title` | 진입 시 풀스크린 타이틀 / HUD / 결과 모달에 표시되는 이름 |
| `intro` | 진입 컷신. `CutsceneStep[]`. 생략 = 빈 배열 `[]` |
| `setup` | 본게임 시작 시점 일괄 실행. `spawn` / `nutrientRegen` / `evolveCommander` / `control` / `place` 등 |
| `waves` | 시간 흐름 이벤트. `{ atSec, steps }` 배열 |
| `timeLimit` | 시간 제한 (초, `gameTime` 기준 — 빨리감기 반영) |
| `endConditions` | 종료 조건 배열. 위에서부터 검사 |
| `stars` | timeout 시 별점 임계 |

### 3.2 setup 에서 쓸 수 있는 step

| step | 동작 |
|---|---|
| `spawn(kind, count, area?)` | 즉시 N개 spawn |
| `control(kind, partial)` | EntityRegistry 갱신 |
| `nutrientRegen(options)` | 부활 영역 설정 |
| `evolveCommander(seconds)` | 진화 트리거 (즉시 advance, 백그라운드) |
| `clear()` | 모든 entity 정리 |
| `place(kind, label)` | placementQueue 에 등록 — setup 후 placing 단계 |
| ⚠️ `narration` / `warning` / `pause` / `waitFor` / `waitForShockwaves` | **무시됨** (setup 은 즉시 실행) |

### 3.3 waves 에서 쓸 수 있는 step

`setup` 과 동일 — `spawn` / `control` / `nutrientRegen` / `evolveCommander` / `clear` / `place`.
**narration / pause / waitFor 등 시간 흐름 step 은 무시.**

```ts
waves: [
  { atSec: 60, steps: [
    spawn('bacteria', 5, { spread: 250, infectedChance: 0.5 }),
    control('macrophage', { speedMul: 1.5 }),
  ]},
],
```

### 3.4 endConditions

```ts
endConditions: [
  { check: 'bacteriaEliminated',     result: 'clear' },
  { check: 'neutrophilsEliminated',  result: 'wipe' },
  // { check: 'whiteCellsEliminated', result: 'wipe' },  // 모든 백혈구 (TCELL/BCELL 포함) 전멸
]
```

`check` 종류는 `waitFor` 와 동일. `result` 는 `'clear'` 또는 `'wipe'`.

**`bacteriaEliminated → clear` 는 다음 조건 모두 만족해야 발동**:
- 모든 wave 가 dispense 완료 (`nextWaveIndex >= waves.length`)
- spawned 카운트 > 0 (false-positive 방지)
- 살아있는 세균 0

### 3.5 stars (timeout 시 별점)

| killed/total 비율 | 별점 |
|---|---|
| `>= twoRatio` (예: 0.8) | ★★ |
| `>= oneRatio` (예: 0.5) | ★ |
| 미만 | 실패 (★0) |

`clear` 시는 항상 ★★★. `wipe` / 실패 시 ★0.

### 3.6 새 스테이지 추가하기

1. `stages/all.ts` 에 `STAGE_N` 객체 정의.
2. 같은 파일의 `STAGES` 배열에 추가:
   ```ts
   export const STAGES: readonly StageConfig[] = [
     STAGE_1, STAGE_2, STAGE_3, STAGE_4, STAGE_5,
     STAGE_6, STAGE_7, STAGE_8, STAGE_9, STAGE_10,
     STAGE_11,  // ← 추가
   ];
   ```

자동으로:
- 스테이지 클리어 후 `[SPACE]` 로 진행 가능
- HUD 에 `STAGE N / title` 표시
- 결과 모달에 stage 정보 표시

## 4. 흐름 다이어그램

```
[게임 첫 진입]
   ↓
CUTSCENE_INTRO 재생 (intro-script.ts, [S]/[ESC] 스킵 가능)
   ↓ end() 또는 스킵
STAGE 1 타이틀 (3초 풀스크린)
   ↓
STAGE 1 intro (narration 등)
   ↓ 클릭 / 자동
배치 단계 (place() 로 등록한 항목들 — 사용자가 클릭으로 위치 지정)
   ↓ 큐 비면
본게임 (setup 일괄 실행 → waves 시간 흐름 → endConditions 검사)
   ↓ clear / wipe / timeout
결과 모달 (키 [SPACE]/[R] + 화면 버튼)
   ↓ 다음 스테이지         ↓ 재시작
특전 선택 화면            같은 스테이지 재시작
   ↓ 카드 3장 중 1개 클릭
다음 스테이지 (특전 누적 + 스킬 충전 +1)
```

**결과 모달 진행** — 키와 버튼 둘 다 (모바일 대응):
- 클리어/timeout ★1+ : `다음 스테이지 ▶` 버튼 또는 `[SPACE]` → 특전 선택 화면
- 항상 : `재시작 ↻` 버튼 또는 `[R]`
- 마지막 스테이지 클리어 : `처음부터 ↻` (stage 0 부터)
- 0★ (wipe/timeout 실패) : `재시작 ↻` 만

**특전 선택 화면** — 다음 스테이지 진입 전. 7종 중 랜덤 3개 카드 → 1개 클릭 선택 (누적).
자세한 특전 목록/효과는 [wiki/명세/진행시스템.md] 참조.

## 4b. 하단 스킬 바 (게임 중)

화면 하단에 `SKILL_BAR_HEIGHT`(64px) 높이의 바 — 게임 영역(`effectiveHeight`)이 그만큼 줄고 그 아래 버튼 2개:

| 버튼 | 동작 | 키 |
|---|---|---|
| `+호중구 (N)` | 호중구 10마리 호출 (게임오버 방지용) | `[N]` |
| `+세균 (N)` | 세균 10마리 호출 — infected 없는 일반 (점수용) | `[B]` |

- 충전 = 호중구/세균 **각각 별도**. 기본 1, 스테이지 클리어마다 +1, 사용 시 -1 (이월).
- `running` phase 에만 표시 — 컷신/배치/결과 모달 중엔 숨김.
- 0 이면 회색 비활성.
- 충전 상태는 `perks.ts` 의 module singleton (`SkillCharges`). 첫 스테이지 진입 시 1/1 초기화.

## 4c. 화면 영역 (effectiveHeight)

`effectiveHeight() = scale.height − (모바일 URL바 80px) − (스킬 바 64px)`.
모든 게임 좌표 (bounds / spawn 영역 / 대식세포 floor / 영양분) 가 이 높이 기준.
모바일(`?mobile`)은 하단 URL 바 가림 + 스킬 바, 데스크탑은 스킬 바만 차감.

## 4d. 모바일 입력

`?mobile` 또는 `?portrait` 접속 시:
- 디버그 텍스트 (좌상단 4줄) 기본 OFF — `[H]` 로 토글.
- **세로 swipe** 로 속도 변경 (↑ 빠르게 / ↓ 느리게). 짧은 탭은 충격파/쉴드.
- 결과 모달 / 특전 / 스킬 모두 버튼이라 키 없이 플레이 가능.

## 5. 디버그 키

스테이지 / 컷신 작성·테스트 편의용:

| 키 | 동작 |
|---|---|
| `[N]` | 호중구 +10 |
| `[B]` | 세균 +10 |
| `[X]` | 대식세포 +1 (무작위 위치, 자동 영역 재분할) |
| `[P]` | 일시정지 |
| `[R]` | 현재 스테이지 재시작 |
| `[S]` / `[ESC]` | 현재 컷신 스킵 |
| `[SPACE]` | 결과 모달에서 다음 스테이지 진행 (1★ 이상) |
| `[1]` / `[2]` / `[3]` | 속도 1× / 2× / 4× |
| `[← →]` | 대식세포 수동 조작 |
| `[Z]` | 페이즈 2 풍선 spawn (디버그) |
| `[M]` | 무작위 변이 적용 |
| `[Shift+1~6]` | 특정 변이 적용 (1=zombie, 2=cancer, 3=corruption, 4=hyperactive, 5=paralysis, 6=chaos) |
| `[I]` | 페이즈 2 인터렉션 모드 토글 |
| `[H]` | 상단 디버그 텍스트 토글 |
