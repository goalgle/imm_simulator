## 1. 프로젝트 개요

- **컨셉**: 바이러스/세균 침입 시 백혈구와 신체 세포의 염증반응을 게임으로 시각화
- **게임 타입**: 시뮬레이션 (최소 유저 인터렉션)
- **렌더링 방식**: 함수 기반 절차적 생성 (비트맵 이미지 미사용)

## 2. 핵심 장면 흐름

### 2.1 모든 세포의 움직임은 함수로 표현된다

```
r(θ, t) = DNA 파라미터 + 임시 상태
```

### 2.2 이 움직임을 표현하는 데이터가 DNA다

```javascript
DNA = {
  shape: { base: 10, w1: { A: 0.3, n: 4, ω: 2.5 }, ... },
  color: { h: 200, s: 60, l: 70 },
  behavior: { target: 1.0, speed: 1.0, contact: 0.35 },
  meta: { recovery: 0.6, divide: 0.0 }
}
```

### 2.3 세균과의 접촉은 DNA를 바꾸지 못하고 함수에만 영향을 준다

```javascript
// 세균 접촉 시
tempState.interference = 0.35;  // 임시 상태만 변경
tempState.damping = 1.0;
// DNA는 그대로!

// 렌더링 함수에서 DNA + 임시 상태 조합
r(θ, t) = DNA.shape.base
        + [DNA.shape.w1.A × (1 - tempState.interference)] × tempState.damping
        + ...
```

### 2.4 바이러스는 DNA를 직접 일부 편집한다

```javascript
// 바이러스 침투 시
virus.infect(cell) {
  cell.DNA.behavior.target = -1.0;  // DNA 직접 변경 (영구적)
  cell.DNA.color.h = 120;           // DNA 직접 변경
  cell.DNA.shape.w1.ω *= 0.6;       // DNA 직접 변경
}
```

### 2.5 요약

| 구분 | 세균 접촉 | 바이러스 감염 |
|---|---|---|
| **영향 대상** | 임시 상태 (tempState) | DNA (영구) |
| **지속 시간** | 일시적 (회복 가능) | 영구적 (변이) |
| **변경 내용** | 형태/움직임만 | 세포 성질 자체 |
| **시각적 효과** | 일시적 왜곡 → 복구 | 색상/형태 완전 변화 |

## 3. 아메바 형태 오브젝트 수학적 설계

### 3.1 권장 방식: 극좌표 변조 + 노이즈 (하이브리드)

```
r(θ, t) = baseRadius
        + A₁ · sin(n₁·θ + ω₁·t)     // 기본 타원 변형
        + A₂ · sin(n₂·θ + ω₂·t)     // 중간 돌기
        + A₃ · sin(n₃·θ + ω₃·t)     // 미세 돌기
        + A_noise · noise(θ, t)      // 불규칙성 (선택)

color = lerp(baseColor, activeColor, activationLevel)
```

#### 파라미터 설명

- `baseRadius`: 기본 반지름
- `Aᵢ`: 각 주파수 성분의 진폭 (변형 크기)
- `nᵢ`: 각도 주파수 (돌기 개수 결정: n=2는 타원, n=3은 3개 돌기)
- `ωᵢ`: 시간 주파수 (변형 속도)
- `t`: 시간
- `θ`: 각도 (0 ~ 2π)
- `baseColor`: 비활성 상태 색상 (밝은 톤)
- `activeColor`: 활성 상태 색상 (어두운 톤)
- `activationLevel`: 활성화 정도 (0~1)

### 3.2 방식별 비교

| 방식 | 수식 복잡도 | 계산 비용 | 자연스러움 | 제어 용이성 |
|---|---|---|---|---|
| 메타볼 | 낮음 | 높음 | ★★★★ | ★★☆ |
| 극좌표 변조 | 중간 | 낮음 | ★★★☆ | ★★★★ |
| 노이즈 기반 | 낮음 | 중간 | ★★★★★ | ★★☆ |
| **하이브리드** | **중간** | **중간** | **★★★★★** | **★★★★** |

> **코드 현실**: 하이브리드 안 채택. 노이즈는 미사용 (성능). [시스템.md](시스템.md) §1.2 렌더링 전략 참조.

## 4. 백혈구 종류별 파라미터 세트 — 옵션 A (옛 의학적 7종 안)

## 7. 백혈구 vs 세균 전투 시스템 (옵션 A — 옛 약화 모델)

> ⚠️ **정합 결정 필요**. 옛 안은 "weakness 0~1 누적 + recovery 자동" 모델. 코드 현실 (옵션 C) 은 "HP 정수 + applyDamage + heal" 모델. [시스템.md](시스템.md) §2.5/§2.6 의 옵션 B/C 참조.

### 7.1 핵심 메커니즘

```
세균 접촉 → 백혈구 약화 (누적)
         ↓
    회복력 < 약화 속도  →  소멸 + 고름 생성
    회복력 > 약화 속도  →  승리 (세균 제거)
```

**중요**:
- 세균은 DNA를 변경하지 않음
- 백혈구는 지속 회복력이 있어 결국 세균을 이김
- 회복력이 따라가지 못하면 소멸

### 7.2 약화 시스템 (Weakening)

```javascript
cell.condition = {
  weakness: 0.0,        // 약화 수치 (0 ~ 1)
  contactCount: 0,
  isAlive: true
};

function updateWeakness(cell, dt) {
  if (cell.isContactingBacteria) {
    cell.condition.weakness += WEAKEN_RATE × dt;
  }
  cell.condition.weakness -= cell.DNA.meta.recovery × dt;
  cell.condition.weakness = clamp(cell.condition.weakness, 0, 1);
  if (cell.condition.weakness >= 1.0) {
    cell.condition.isAlive = false;
    createPus(cell.position);
  }
}
```

### 7.3 약화 효과 3가지

1. **크기 감소**: `renderRadius = base × (1 - 0.5 × weakness)`
2. **색상 탈색**: `s = base.s × (1 - 0.6 × weakness)`, `l = base.l × (1 - 0.3 × weakness)`
3. **운동성 저하**: `moveSpeed = base.speed × (1 - 0.7 × weakness)`, `ω' = ω × (1 - 0.5 × weakness)`

### 7.4 고름 (Pus) 시스템 🟡

- 백혈구 소멸 시 / 세균 제거 성공 시 일부 호중구 사망 (확률적)
- 대식세포가 흡수해 정리

> **코드 현실**: 코드는 weakness 대신 HP 시스템. 시체 (corpse) 가 화면 바닥으로 낙하 → 대식세포가 흡수 → 점수 누적 → 새 호중구 생산. 컨셉상 옛 "고름" 의 진화형이지만 메커니즘 다름.

## 8. 접촉 반응 시스템 (옵션 A — 옛 tempState 모델)

> ⚠️ **정합 결정 필요**. 옛 안은 "tempState (interference/damping/phaseShock) 3 변수 + 시간 감쇠". 코드 현실 (옵션 C) 은 "VisualState (shock/combat/life) 3 채널 + 렌더러가 합성". [시스템.md](시스템.md) §2.5 참조.

### 8.1 핵심 원리

세균 접촉은 DNA 를 변경하지 않음. 함수 계산에 사용되는 임시 상태값만 변경.

```javascript
const tempState = {
  interference: 0,        // 간섭 강도 (0 ~ 1)
  damping: 1.0,          // 감쇠 계수 (1.0 → 0)
  phaseShock: [0, 0, 0], // 위상 충격 (각 wave별)
  contactTime: null      // 접촉 시각
};
```

### 8.2 렌더링 함수 (DNA + 임시 상태 조합)

#### 접촉 후

```javascript
Δt = t - tempState.contactTime

r(θ, t) = DNA.shape.base
        + [DNA.shape.w1.A × (1 - tempState.interference)]
          × sin(DNA.shape.w1.n × θ + DNA.shape.w1.ω × t + tempState.phaseShock[0])
          × tempState.damping
        + ...

여기서:
- DNA 값은 그대로 (변경 없음)
- tempState 값만 변경됨
- 시간 지나면 tempState가 초기값으로 복귀
```

### 8.3 위상 충격 (Phase Shock) 💥

세균 접촉 시 10% 확률로 발동. 각 wave 의 위상이 무작위로 어긋남.

```javascript
if (Math.random() < 0.1) {
  cell.tempState.phaseShock = [
    random(π/3, 2π/3),
    random(π/4, π/2),
    random(0, π/4)
  ];
}
```
