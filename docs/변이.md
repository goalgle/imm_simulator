> 2026-05-01 작성. JS dna 변경만 정의. 시스템 분기 (정지/낙하/분열/scale 등) 미정.

## 바이러스 변이 시나리오 (총 6종)

### 1. 좀비화 (Zombie) 🧟

**효과**: 아군 공격

```javascript
mutation_zombie(dna) {
  dna.behavior.target = -1.0;          // 아군 공격
  dna.color.h = 120;                   // 녹색
  dna.color.s = 40;                    // 채도 낮춤 (탁함)
  dna.shape.w1.ω *= 0.6;               // 느려진 움직임
  dna.shape.w2.ω *= 0.6;
}
```

**시각적 변화**: 녹색 + 느린 떨림

---

### 2. 암세포화 (Cancer) 🦠

**효과**: 무한 증식

```javascript
mutation_cancer(dna) {
  dna.meta.divide = 0.3;               // 30% 분열 확률
  dna.shape.base *= 1.4;               // 비대화
  dna.behavior.contact = 0.1;          // 에너지 소모 감소
  dna.color.l = 40;                    // 어두워짐
  dna.shape.w1.A *= 1.3;               // 돌기 커짐
}
```

**시각적 변화**: 크고 어둡고 돌기 많음

---

### 3. 형태 붕괴 (Corruption) 💥

**효과**: 비정상적 형태

```javascript
mutation_corruption(dna) {
  dna.shape.w1.A *= -0.8;              // 진폭 반전
  dna.shape.w2.n = 13;                 // 기괴한 주파수
  dna.shape.w3.n = 7;
  dna.color.h = 0;                     // 빨강
  dna.color.s = 80;
  dna.behavior.speed *= 1.3;           // 빠른 움직임
}
```

**시각적 변화**: 빨강 + 뒤틀린 형태 + 빠름

---

### 4. 과민화 (Hyperactive) ⚡

**효과**: 과도한 반응, 빠른 소진

```javascript
mutation_hyperactive(dna) {
  dna.shape.w1.ω *= 3.0;               // 매우 빠른 진동
  dna.shape.w2.ω *= 3.0;
  dna.shape.w3.ω *= 3.0;
  dna.behavior.contact = 0.7;          // 접촉 시 큰 충격
  dna.meta.recovery = 0.2;             // 느린 회복
  dna.color.h = 45;                    // 주황
  dna.color.s = 90;
}
```

**시각적 변화**: 주황 + 격렬한 떨림

---

### 5. 마비화 (Paralysis) 🧊

**효과**: 움직임 정지

```javascript
mutation_paralysis(dna) {
  dna.shape.w1.ω = 0.1;                // 거의 멈춤
  dna.shape.w2.ω = 0.2;
  dna.shape.w3.ω = 0.1;
  dna.behavior.speed = 0.1;            // 이동 거의 불가
  dna.color.h = 210;                   // 청색
  dna.color.l = 80;                    // 밝은 청색 (얼어붙음)
  dna.shape.w1.A *= 0.3;               // 작은 변형
}
```

**시각적 변화**: 밝은 파랑 + 거의 정지

---

### 6. 카오스화 (Chaos) 🌀

**효과**: 예측 불가능한 행동

```javascript
mutation_chaos(dna) {
  dna.shape.w1.n = random(2, 15);      // 랜덤 주파수
  dna.shape.w2.n = random(2, 15);
  dna.shape.w3.n = random(2, 15);
  dna.shape.w1.ω = random(0.5, 5.0);   // 랜덤 속도
  dna.behavior.target = random(-1, 1); // 랜덤 대상
  dna.color.h = random(0, 360);        // 랜덤 색상
  dna.color.s = random(50, 100);
}
```

**시각적 변화**: 매번 다른 형태/색상/움직임

## B. 옵션 B — Session 17 정의 (시스템_구현 §2.12)

> Session 17 갱신. dna 변경 + 시스템 분기 메커니즘 + Stage 11~15 작업 분해.

### 2.12 페이즈 2 게임 룰 (Session 15 락인 → Session 17 갱신)

§2.11 의 진입/복귀 골격 위에 **실제 게임 룰** 정의. 아이디어 기획서 §"바이러스 변이 시나리오 (총 6종)" 의 변이 함수를 트리거하는 메커닉.

> **Session 17 갱신**: 쉴드 단일화 (3×3 매트릭스 폐기) + 변이 6종 메커니즘 상세 정의. 이전 안에서 미정 부분이 사용자 디자인으로 확정됨.

#### Wave 모델 (1 wave / 페이즈 2 진입)

| 항목 | 값 |
|---|---|
| Wave 당 바이러스 수 | **10발** 순차 spawn (시간차 ~0.8s) |
| 바이러스 패턴 분포 | 직진 4 / 지그재그 3 / 커브 3 (매 wave shuffle) |
| 바이러스 속도 | spawn 시 40~80 px/s 랜덤 — 도달 타이밍 분산 (한 번의 쉴드로 다발 차단 유도) |
| 쉴드 charges | **5회** (Session 17 — 이전 8회 안 폐기) |
| 쉴드 지속 | 0.3s |
| Wave 종결 | 10발 모두 처리 (쉴드 차단 or DNA 도달) → 변이 판정 → 페이즈 1 복귀 |

#### Hit → 변이율 모델

각 hit 마다 mutation rate +10%. 누적 0~100%.

| hit | 변이율 | 결과 변이 |
|---|---|---|
| 0 | 0% | 정상 (변이 없음) |
| 1~2 | 10~20% | 변이 1 좀비 |
| 3~4 | 30~40% | 변이 2 암세포 |
| 5~6 | 50~60% | 변이 3 형태 붕괴 |
| 7~8 | 70~80% | 변이 4 과민 |
| 9 | 90% | 변이 5 마비 |
| 10 | 100% | 변이 6 카오스 |

매핑은 결정형 (랜덤 X). hit 카운트만으로 변이 종류 결정.

#### DNA 시각화 — 10 세그먼트

DNA 나선을 시각상 10 구간으로 분할. 매 hit 마다 1 세그먼트가 corrupted (빨강 톤) 으로 변경 — 인덱스 0 부터 순차.

⚠️ 세그먼트는 **시각용 추상** 이지 실제 DNA 형질의 1:1 매핑 아님 (현 단계). hit 카운트만이 게임 로직에 영향. 추후 §3.3 매핑 정의 시 실제 DNA 형질에 연결할 수 있음.

#### 쉴드 (Session 17 단일화)

이전 안 (3×3 쉴드/바이러스 매트릭스, [1]/[2]/[3] 키 선택) **폐기**. 게임 디자인 재검토 결과 매트릭스 매칭은 학습 부담만 ↑ 즐거움 ↓ 로 판단. 단일 쉴드 + 바이러스 속도 랜덤화로 "타이밍" 만 핵심으로.

- 클릭 = 쉴드 발동 (charges 남고 비활성일 때만)
- 활성 0.3s 동안 DNA 중심 도달한 바이러스 = `hits` 미증가 + 즉시 소멸 + 차단 이펙트 (시안 원 펄스)
- 쉴드 시각: DNA 자체 strand/pair 라인 두께 ↑ (별도 영역 X — DNA 자체에 형성됨)
- 한 번의 발동으로 같은 타이밍의 다발 바이러스 다 차단 가능
- 바이러스 속도 랜덤 (40~80 px/s) → 빠른 놈/느린 놈 도달 타이밍 분산 → 유저가 "몰린 순간" 잡아야 함

#### 변이 적용 흐름

```
Wave 종결
  ↓
hits 카운트 → pickMutation(hits) → MutationKind | null
  ↓ (null 이면 변이 X)
host.dna = applyMutation(host.dna, kind)  // host 전용 클론에 적용
  ↓
CellRenderer handle 갱신 (재생성 또는 setDna)
  ↓
"변이 N 발생" 텍스트 1~2초 표시
  ↓
페이즈 1 복귀 — 변이된 호중구는 새 DNA 로 동작 (drives/color/speed 자동 반영)
```

⚠️ **호중구 DNA 인스턴스화 필수**: 현재 모든 NEUTROPHIL 이 같은 DNA 객체 reference 공유 (`dna === NEUTROPHIL`). 변이 = 그 reference 변형하면 모든 호중구 변이 버그. **호스트 cell 별 DNA 클론** 필요. 이는 Stage 2 의 큰 회귀 위험 작업 — `cell.dna === NEUTROPHIL` 같은 reference 비교를 `cell.dnaKind` 같은 라벨 비교로 전환.

#### 변이 6종 메커니즘 (Session 17 상세 정의)

각 변이는 페이즈 1 시스템 (ContactSystem, WhiteCellBehaviorSystem, MacrophageSystem 등) 에 분기로 구현. 시스템은 `WhiteCell.mutation: MutationKind | null` 로 식별. `dna.kind` 는 변이 후에도 'NEUTROPHIL' 유지 (호중구 정체성).

| 변이 | dna 변경 (mutations.ts) | 시스템 메커니즘 | 시각 |
|---|---|---|---|
| **1 좀비** | target=-1, 녹색 (h=120,s=40), 떨림 ↓ | 호중구 우선 공격, fusion 비활성, 세균 접촉=정상 데미지 / 호중구 접촉=공격력 ×2 | 녹색 + 천천한 떨림 |
| **2 암세포** | 색 어두움 (l=40) 만 | 정지 + 즉시 바닥(큰 Y) 낙하, ~6s 후 좌우 분열, 대식세포 진로 차단 | 어두운 정적 덩어리 |
| **3 붕괴** | 진폭 반전, 빨강 (h=0,s=80), 속도 ×1.3 | 매 프레임 scale 점감 (5s, 1→0), 소멸 시 BloodScene 에 페이즈 2 자동 진입 시그널 | 격렬 떨림 + 작아짐 |
| **4 과민** | 떨림 ×3, 주황 (h=45,s=90) | 매 프레임 scale 점증 (4s, 1→2.5), 임계 도달 시 폭발: 반경 ~200px 내 모든 살아있는 호중구/세균 즉사 + 본인 소멸 | 격렬 떨림 + 커짐 → 폭발 |
| **5 마비** | 색 밝은 파랑 (h=210,l=80) 만 | 평소 일반 호중구 동작, 3s 주기 0.5s 마비 (행동 정지), 마비 시 인접 ~60px 호중구도 0.5s 마비로 전파 | 평상시 정상, 주기적 정지 펄스 |
| **6 카오스** | 모든 형질 랜덤 (n, omega, target, color) | 호중구↔호중구 + 호중구↔세균 모두 공격, 데미지 ×3, prey = 모든 살아있는 LivingCell | 무작위 색/모양 |

**dna 변경의 시스템 의존**: dna 가 매 프레임 행동 시스템에 읽히므로 자동 반영. mutations.ts 함수는 dna 의 시각/기본 행동 형질만 변경하고, "행동 메커니즘 (정지/낙하/분열/scale/timer/폭발)" 은 시스템에서 `WhiteCell.mutation` 으로 분기.

#### 좀비 vs 카오스 — 호중구↔호중구 분기 공유

좀비 (호중구 우선 공격, 세균은 정상) 와 카오스 (호중구+세균 모두) 는 둘 다 호중구↔호중구 공격 분기가 필요. ContactSystem 에 한 번만 추가하고 mutation 으로 분기:
- mutation==='zombie' → 호중구↔호중구 페어, 호중구 vs 데미지 ×2
- mutation==='chaos' → 호중구↔호중구 + 호중구↔세균 모두, 데미지 ×3

## C. 옵션 C — 코드 현실 (mutations.ts Session 17 갱신)

> 2026-05-07 갱신. 사용자 디자인 반영 — 암세포 base 변경 제거 (모양 유지), 마비 speed 변경 제거 (정상 동작), 등.

| 변이 | dna 변경 (mutations.ts) | 시스템 분기 (Stage 11~15 예정) |
|---|---|---|
| 좀비 | `target=-1`, 녹색 (`h=120,s=40`), `w1/w2 omega ×0.6` | ContactSystem 호중구↔호중구 분기, fusion 비활성, 호중구 vs 공격력 ×2 |
| 암세포 | 색 어두움 (`l=40`) **만** | WhiteCell cancer 모드 — 정지 + 바닥 낙하 + 6s 후 좌우 분열, MacrophageSystem 충돌 |
| 붕괴 | `w1.A ×-0.8`, `w2.n=13`, `w3.n=7`, 빨강 (`h=0,s=80`), `speed ×1.3` | WhiteCell corruption 모드 — 5s scale 1→0, 소멸 시 페이즈 2 자동 진입 |
| 과민 | `w1/w2/w3 omega ×3`, 주황 (`h=45,s=90`) | WhiteCell hyperactive 모드 — 4s scale 1→2.5, 임계 폭발 (반경 200px 즉사) |
| 마비 | 색 밝은 파랑 (`h=210,l=80`) **만** | WhiteCell paralysis 모드 — 3s 주기 0.5s 마비, 인접 60px 호중구 전파 |
| 카오스 | 모든 형질 랜덤 (n, omega, target, color) | ContactSystem 호중구↔호중구+호중구↔세균, 데미지 ×3, prey = 모든 살아있는 LivingCell |

### C.1 옵션 A 와의 주요 차이

- **암세포**: A 에선 `base ×1.4` (비대화) + `w1.A ×1.3` (큰 돌기) + `meta.divide=0.3` + `behavior.contact=0.1`. C 에선 모두 제거. 이유: Session 17 디자인 — "모양 유지한 채 바닥 낙하". 비대화는 시스템 분기 (정지+낙하) 의 시각 일부로도 표현 가능하지만 사용자 명시적 디자인 반영.
- **과민**: A 의 `behavior.contact=0.7` + `meta.recovery=0.2` 제거. 이유: 시스템 분기에서 처리.
- **마비**: A 의 `omega 0.1/0.2/0.1` + `speed=0.1` + `w1.A ×0.3` 모두 제거. 이유: Session 17 디자인 — "일반 호중구처럼 동작 + 주기적 마비". A 의 "거의 정지" 안 폐기.
- 좀비/붕괴/카오스: A 와 C 동일.

### C.2 시스템 분기 식별자

`WhiteCell.mutation: MutationKind | null`. dna.kind 는 변이 후에도 'NEUTROPHIL' 유지 (호중구 정체성). mutation 필드로 시스템이 분기.

```typescript
class WhiteCell extends LivingCell {
  mutation: MutationKind | null = null;
  setMutation(kind: MutationKind | null): void { this.mutation = kind; }
}
```

`finalizeWave` (BloodScene) 에서:
```typescript
const newDna = applyMutation(host.dna, kind);
host.setDna(newDna);
host.setMutation(kind);
```

## 4. 변이 전파 모델

### 4.1 식별된 어색함

> "장면 2의 결과는 장면 1의 모든 B세포에 동일 적용"

- 한 세포 감염이 즉시 전체로 점프 → 직관 위배
- 부분성공(`protectionRate`) 표현 어려움

### 4.2 채택안: **점진적 분열 전파**

```
감염 B세포 1개
  ↓ (DNA.meta.divide > 0 이므로 분열)
변이 B세포 2개 → 4개 → 8개 ...
  ↓ (시간 경과)
화면의 B세포 비율이 점진적으로 변이로 치환됨
```

- 부분성공: `protectionRate`에 비례하여 `meta.divide` 값을 낮춤 → 전파 속도 ↓
- 시각적 드라마: 점점 색이 바뀌는 군집
